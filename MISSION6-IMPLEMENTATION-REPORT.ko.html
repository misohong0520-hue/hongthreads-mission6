미션 6 구현·검증 보고서

핵심 CRUD·파일·개인 세션·원본 연결의 로컬 구현과 실제 Supabase 검증을 마쳤습니다.
현재 수정본은 배포 승인 대기입니다. 이 보고서는 모든 외부 업무가 검증됐다는 뜻이 아닙니다.

현재 버전과 승인 범위

사용자의 “배포는 승인후 진행” 지시 이전에 최초 버전 c440144가 AWS에 배포되어 있습니다. 지시 이후 수정한 코드는 로컬에만 준비했습니다. 서버 파일·설정 변경, 업로드, 운영 서비스 재시작은 추가로 수행하지 않았습니다.

공개 주소는 https://hongthreads.hongsik.blog이고, 기존 WordPress와 별도 서비스로 동작합니다. 전용 비공개 GitHub 저장소는 hongthreads-mission6입니다. 현재 저장소의 공개된 최신 커밋과 로컬 수정본은 다릅니다.

현재 공개 버전의 알려진 문제: Linux WIF worker에 앱의 VERTEX_TRANSPORT=local 값이 전달돼 AI 연결이 준비되지 않습니다. 기존 worker를 교체하지 않고 로컬 어댑터에서 환경을 분리하는 수정과 검사를 완료했습니다. 서버 반영은 승인 후에 합니다. 수정본에는 React 초기화 충돌, 다중 탭의 세션 교체 경합, 확장 프로그램 업로드, 원본 본문 동기화 수정도 포함됩니다.

완료 판정의 범위

미션 6의 Supabase CRUD·파일·새로고침 유지 흐름은 로컬에서 실제 저장소로 확인했습니다. 전체 원본 기능은 원본 서비스와 계정 권한에 계속 의존합니다. 화면 검사 통과를 모든 외부 업무의 성공으로 계산하지 않았습니다.

  • 실제 Threads 게시·예약·댓글, 구독·결제, 외부 계정 추가·삭제는 실행하지 않았습니다. 지정 테스트 계정과 승인된 내용으로 별도 검증해야 합니다.
  • 새 확장을 실제 Chrome에 설치해 로그인된 Threads 페이지에서 끝까지 수집하는 흐름은 미검증입니다. 업로드·키·URL 작업 API 계약과 실제 Storage 저장은 검증했습니다.
  • 쿠팡·토스·브랜드커넥트의 모든 상품 선택→링크 발급→발행 조합과 영상 분석·재생은 이번 수정본의 종단 검사에서 모두 실행하지 않았습니다. 원본 연결 상태와 권한을 그대로 사용합니다.
  • 원본의 외부 미디어는 출처 URL을 보존합니다. 모든 원본 S3 파일을 Supabase로 일괄 복사한 상태는 아닙니다. 개인 보관함 신규 업로드는 Supabase Storage에 저장합니다.
  • 원본 성공 후 DB 저장이 실패하면 동기화 대기 이력을 남깁니다. 외부 작업을 자동으로 재실행하지 않으며, 운영용 자동 재조정·장기 미참조 파일 정리는 추가 운영 과제로 남습니다.
  • 현재 계정에서 노출되지 않는 WDRB를 일반 기능의 장애로 계산하지 않습니다. 원본 공용 보관함·제휴 공급자의 접근 권한을 새 앱에서 만들어 주지 않습니다.
  • 현재 수정본의 Linux CI 및 공개 HTTPS 재검증은 배포 승인 후 진행합니다. 전용 GitHub 저장소는 비공개여서 과제 평가자 접근 권한을 별도로 제공해야 합니다.

승인 후 반영할 작업

  1. 검토된 로컬 스냅샷을 전용 저장소에 반영하고 Linux CI를 통과시킵니다.
  2. 새 release를 AWS에 업로드해 HongThreads 두 서비스만 전환합니다. 기존 WordPress·DB·Vertex worker는 유지합니다.
  3. WIF 준비 상태·HTTPS·세션·CRUD·파일을 다시 확인합니다. 검사 실패 시 직전 release로 복구합니다.
  4. 공개 도메인에서 실제 원본 연결·AI·미션 6 CRUD QA 결과와 제출 자료를 갱신합니다.

비밀값은 이 보고서와 저장소에 포함하지 않습니다. 이 보고서는 교육기관이 Vercel 대신 AWS 제출을 승인했다는 확인서가 아닙니다.
