HongThreads의 데이터 저장·파일 처리·AI 연결과 AWS 배포 환경을 구현했습니다.
이번 보완은 제출 문서 정리와 필수 QA입니다. 실행 서비스와 화면은 변경하지 않았습니다.

서비스 소개

Threads 콘텐츠 작성, 트렌드 확인, 벤치마킹 자료 관리와 AI 활용을 제공하는 웹 프로젝트입니다. 배포 주소는 https://hongthreads.hongsik.blog이며, 소스는 공개 GitHub 저장소에 있습니다.

핵심 구현

  • Supabase 19개 테이블과 비공개 Storage를 사용하는 자료·첨부 저장.
  • 입력값·소유권·첨부 참조·수정 버전 검사와 오류 처리.
  • 벤치마킹 자료 등록·목록·상세 확인·수정·삭제와 화면 반영.
  • 원고·편집 세션·페르소나·댓글 양식·분석·작업 이력 관리.
  • Vertex AI WIF 연결과 생성 결과 저장.
  • Nginx HTTPS·systemd·버전별 릴리스·롤백 및 GitHub Actions 검사.

QA 결과

CRUD·입력 오류 요청은 /workspace/api/v1 데이터 API로 전송하고, 보관함 화면에서 카드·이미지 표시와 새로고침 후 반영을 확인했습니다.

2026-11-11 공개 HTTPS에서 임시 자료와 파일로 세부 검사 14개 통과·실패 0개를 확인했습니다. 브라우저 JavaScript 오류는 0건이며 임시 자료·폴더·파일 정리를 완료했습니다.
