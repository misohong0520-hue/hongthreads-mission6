완료 판정의 범위

미션 6의 Supabase CRUD·파일·새로고침 유지 흐름은 로컬과 공개 HTTPS에서 실제 저장소로 확인했습니다. 전체 원본 기능은 원본 서비스와 계정 권한에 계속 의존합니다. 화면 검사 통과를 모든 외부 업무의 성공으로 계산하지 않았습니다.

  • 실제 Threads 게시·예약·댓글, 구독·결제, 외부 계정 추가·삭제는 실행하지 않았습니다. 지정 테스트 계정과 승인된 내용으로 별도 검증해야 합니다.
  • 새 확장을 실제 Chrome에 설치해 로그인된 Threads 페이지에서 끝까지 수집하는 흐름은 미검증입니다. 업로드·키·URL 작업 API 계약과 실제 Storage 저장은 검증했습니다.
  • 쿠팡·토스·브랜드커넥트의 모든 상품 선택→링크 발급→발행 조합과 원본 아카이브에서 선택하는 전체 영상 분석·대용량 재생은 실행하지 않았습니다. 작은 합성 영상의 서버 분석과 사용법 iframe 로드만 해당 범위에서 확인했습니다. 원본 연결 상태와 권한을 그대로 사용합니다.
  • 원본의 외부 미디어는 출처 URL을 보존합니다. 모든 원본 S3 파일을 Supabase로 일괄 복사한 상태는 아닙니다. 개인 보관함 신규 업로드는 Supabase Storage에 저장합니다.
  • 원본 성공 후 DB 저장이 실패하면 동기화 대기 이력을 남깁니다. 외부 작업을 자동으로 재실행하지 않으며, 일반 동기화 대기의 자동 재조정·장기 미참조 파일 정리는 추가 운영 과제로 남습니다.
  • 현재 계정에서 노출되지 않는 WDRB를 일반 기능의 장애로 계산하지 않습니다. 원본 공용 보관함·제휴 공급자의 접근 권한을 새 앱에서 만들어 주지 않습니다.
  • 현재 수정본의 Linux CI 및 공개 HTTPS 재검증은 위 범위에서 완료했습니다. 전용 GitHub 저장소는 비공개여서 과제 평가자 접근 권한을 별도로 제공해야 합니다.
